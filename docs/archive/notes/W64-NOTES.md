# W-64：改名北辰、星图标、强调色可配、卡片改毛玻璃（2026-10-27）

用户原话：「设计一个好看点符合这个应用的图标，名字改一个好听点的……UI 重新设计，那些功能重新排版，排的好看一点，正确一点……不要太素了，然后那些什么的换成毛坯玻璃」。

## 一、名字：北辰

候选走过一轮（代劳 / 掌令 / 枢机 / 白泽 / 北辰）。用户否掉白泽的理由很直接：
**「感觉有点像人名了」**。

「北辰」的好处：

- 出自《论语·为政》「为政以德，譬如北辰，居其所而众星共之」——北极星不动，众星绕着它转。
  这正是 Agent 的姿势：你不动，它替你去跑。
- 两个字、去声 + 阳平，念着不拗口，也不生僻。
- 和图标是一套：夜空蓝底 + 一颗金星。

改的位置：`AndroidManifest` 的 `android:label`、两个前台服务的 label、无障碍服务描述。

## 二、图标：矢量四角星

**没走 AI 生图。** 先生成过三版（约 15~30 credits），问题都一样：线条毛边、带
「AI 生成」水印、缩小到 48dp 糊成一团。图标是几何图形，按坐标画比生图准得多。

- 前景：`drawable/ic_launcher_foreground.xml`，108dp 画布上的四角星（外半径 30、内半径 9，
  落在 66dp 安全区里）
- 背景：`#16233A`（夜空蓝）
- `mipmap-anydpi-v26/ic_launcher.xml` + `ic_launcher_round.xml`，含 `<monochrome>`
  （Android 13+ 主题图标会用它渲染成单色）

minSdk = 26，正好是 adaptive icon 的下限，所以**没有生成任何位图 mipmap**——
少 10 个 png，也少一处会在高密度屏上糊的东西。

## 三、强调色：五个预设 + 自定义

`AccentPreset`：星金（默认）/ 天青 / 松绿 / 赭石 / 青紫，每个给 light/dark 两个值
（同一色相在深色底上必须提亮，否则 `#22406B` 放在 `#17110E` 上几乎看不见）。

自定义走 HEX 输入（`#RRGGBB`），不做色轮——色轮在手机上要占一整屏，而用户真正想要的
是「接近某个色」，不是调 HSV 三个滑杆。

### 为什么只替换 primary 族

`accentColorScheme()` 只改 primary / primaryContainer / secondary / tertiary，
背景、表面、描边、语义色全部保留。理由：**品牌感由 primary 承载，可读性由
background/surface/onSurface 决定**。只动前者，用户选个荧光黄也不会把界面变成白底白字。

`onPrimary` 按 luminance 自动切黑/白（`#D2A85E` 上的白字只有 1.9:1 对比度，必须压深字）。

### 外观偏好落盘

原来主题三选是 `rememberSaveable`，进程一死就回默认。对明暗模式勉强说得通，
但**自定义色不落盘等于白设**——用户挑完色，重启回到金色，只会觉得功能坏了。

新增 `AppearanceState`（object + `mutableStateOf` + SharedPreferences）：
读它就自动订阅，改一处全 App 重组。它必须活得比任何 ViewModel 都久，
因为 `AgentKitTheme` 在 `setContent` 最外层。

## 四、毛玻璃：三件套，不用 blur

`glassFill()` / `glassBorder()`：

- 浅色：白 88%（底是暖白，半透明白会透出底色，形成雾面而不是纯白板）
- 深色：白 6%（一层薄雾，靠下面透上来的光晕）
- 边缘：深色是白 12% 反光，浅色是一道极淡描边

**没用 `Modifier.blur()`**：需要 API 31+，且会把文字一起糊掉。iOS 的 grouped list
也是「半透明 + 亮边」，纯色底上一样成立。

## 五、验收

1. 桌面图标是深蓝底 + 金星，通知栏小图标也是星（monochrome）
2. 设置 → 外观 → 主题色：五个色点 + 「默认」+ 自定义 HEX 输入
3. 点任意预设 → 按钮、开关、选中态立刻变色；杀掉 App 重开仍是那个色
4. 深色主题下选「赭石」→ 颜色会自动提亮，不会糊在背景里
5. 卡片边缘有一道细亮边，浅色下能看出是「一层」而不是画上去的白块

## 六、遗留

- 设置页的结构重排（10 组 → 4 组、备用 Key 搬走）还没做，本轮只动了材质与配色。
- 毛玻璃在纯色背景上效果偏弱。等做了页面级背景（渐变/光斑）才会明显——那一步要改
  所有页面的根容器，风险比收益大，先留着。
