## 一、这次交付了什么

给 AgentKit 装上运行层的第一块基石：**能力契约 + 本地模型空闲自动卸载**。

效果（真机可验证）：
- 本地模型闲置 5 分钟后自动卸载，释放 native 内存、降温、让 SoC 睡觉；
- 下一轮对话时由现有 `ensureModelLoaded()` 自动重载，用户只感知首 token 稍慢；
- 卸载 / 就绪事件写入运行日志（AgentLogger），日志页可见；
- 生成中途绝不卸载（两道闸门：在途计数 + 引擎延迟回收，见代码注释）。

## 二、新增文件（app/src/main/java/com/example/agentkit/runtime/）

| 文件 | 内容 |
|---|---|
| `AgentCapability.kt` | 能力契约（`AgentCapability` 接口 + 状态枚举）+ `CapabilityRegistry` 注册表（按需启动、依赖递归拉起、幂等） |
| `IdleUnloadPolicy.kt` | 通用空闲释放节拍器：30 秒一轮检查，超时且资源自报可安全释放才动手 |
| `LocalLlmRuntime.kt` | 本地模型生命周期运行时（单例：计数/节拍/配置）+ `wrapLocalLlm()` 轻装饰器（每轮包装，与工厂节奏一致） |

设计原则：**契约只有生命周期，没有业务**。推理本体（LocalLlamaClient）一行未动。

## 三、现有文件改动（各一处，可回滚）

1. `AgentKitApplication.kt`
   - `onCreate` 里 AdbSession.init 之后新增一行 `runCatching { LocalLlmRuntime.init(this) }`
   - 全程轻操作（建 SharedPreferences + 注册 + 起 30s 节拍协程），不拖慢冷启动；失败静默降级为「常驻不卸载」。

2. `ui/ChatViewModel.kt`
   - 供应商工厂 `registerProvider("local-llama")` 里，把创建出的客户端包一层：
     `wrapLocalLlm(LocalLlamaClient(...))`
   - 顶部新增两个 import（`LocalLlmRuntime` / `wrapLocalLlm`）。

## 五、配置入口（给设置页预留）

`LocalLlmRuntime.enabled`（默认开）、`LocalLlmRuntime.idleTimeoutMinutes`（默认 5，1~120）。
已持久化在独立 SP 文件 `agentkit_runtime`，不与 `LocalLlamaSetting` 互相污染。设置页想加开关时直接绑定这两个存取器即可。
